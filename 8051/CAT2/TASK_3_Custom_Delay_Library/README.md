# TASK 3 Custom Delay Library

Task project for CAT2. The experiment record (aim, circuit, logic, inference) is in [`../README.md`](../README.md).

- Keil project: `day1task.uvproj`
- Source code: `delay.c`, `prog1.c`
- Startup file: `STARTUP.A51`
- Firmware: `Objects/day1task.hex`, built with SDCC 4.2.0 (`sdcc -mmcs51`) from the code in this folder, because Keil C51 was not available. A Keil C51 build gives a different hex file for the same program.
